# 📸 Captures d'écran — Laboratoire Active Directory

Ce dossier regroupe les captures d'écran réalisées lors de mes travaux pratiques sur Windows Server.

## Objectifs

- Configuration réseau de Windows Server.
- Installation et configuration du rôle Active Directory Domain Services (AD DS).
- Diagnostic des erreurs d'installation.
- Utilisation de PowerShell et DISM pour le dépannage.
- Vérification des fonctionnalités et des mises à jour Windows Server.

## Documentation

Les captures illustrent notamment les opérations de diagnostic effectuées sous Windows Server 2019.

Le projet comprend également des travaux d'administration Active Directory sous Windows Server 2022.
